# Lets Icons

Icons by Leonid Tsvetkov, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Selected from the [Figma pack](https://www.figma.com/design/anoGY6uT9hzJJTGoZggc7N/Free-Icon-Pack-1800--icons--Community-?node-id=2-27) requested for Luy Manager. The author's [original community file](https://www.figma.com/community/file/886554014393250663) is credited by the [Iconify distribution](https://github.com/iconify/icon-sets/blob/master/json/lets-icons.json), which supplies these local SVGs. SVG shapes are unchanged; CSS masks apply the app's colors.

Only the icons used by the app are bundled. No network request to Figma or Iconify is needed at runtime.

Local changes: `menu.svg` carries `stroke-width="2"` so it matches the rest of the set. `wifi`, `candlestick`, `sparkle` and `chat-smile` are not from the pack. They are drawn in the same 24px, 2px-stroke style for categories the pack has no glyph for.
